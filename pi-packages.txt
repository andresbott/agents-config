# Pi packages/plugins to install on `make pi-install` (one source per line).
# Blank lines and lines starting with # are ignored. Sources take the same
# forms as `pi install`: npm:pkg, npm:@scope/pkg, git:…, https://…, ./local/path
# (a bare name with no prefix is treated as a local ./path, not a registry pkg).
#
# To load only part of a package, write the line as the JSON object Pi keeps in
# settings.json (one line, starting with `{`). `make pi-install` installs its
# `source`, then swaps the plain-string settings entry for this object. It seeds
# the filter only once: an entry that is already an object (e.g. edited in
# `pi config`) is left alone. Filters narrow what loads, not what is cloned.
#   {"source":"git:github.com/owner/repo","skills":["skills/one"]}
